Getting Started

  • Open Matrix Evolutions
  • Click LOGIN WITH AUDIOTOOL and log in with your Audiotool account
  • Open a project on beta.audiotool.com that contains a Heisenberg or Pulverisateur synth
  • Copy the project URL from the browser

Drawing Notes

  • Double click on the piano roll to add a note
  • Double click on an existing note to remove it
  • Drag a note to move it
  • Ctrl + Drag to copy a note
  • Drag the right edge of a note to resize it
  • Click on a piano key on the left to preview the sound

Arpeggiator Settings

  • VELOCITY – overall note volume
  • REPEAT – how many times each note repeats before moving to the next
  • GATE – note length relative to the rate
  • DIRECTION – Up, Down, Up/Down, Zig Zack or Random
  • OCTAVES – spread the arpeggio over 1–4 octaves
  • RATE DIV – how fast the arpeggiator plays (1/4, 1/8, 1/16, 1/32)
  • SNAP – note size when drawing in the piano roll
  • BPM – drag up/down to set tempo

Writing to Audiotool

  • Paste your Audiotool project URL in the field at the bottom
  • Select HEISENBERG or PULVERISATEUR
  • Click ▶ WRITE TO AUDIOTOOL
  • The arpeggio appears as a note region in your project
Important: After writing, set the loop marker in Audiotool to 4 bars to hear the full pattern!
